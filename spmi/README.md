# RP2040 passive SPMI experimental decoder
GP2 SCLK, GP3 SDATA; USB CDC CoolTerm. SID 00/06/09 candidate frames only.
Not GusmanB firmware. No claim of lossless 20MHz SPMI capture or validated read turnaround.
Build with Pico SDK 2.0.0 for Raspberry Pi Pico. Output pico_spmi_sniffer.uf2.
WARNING: this is a prototype and has not been hardware tested.
